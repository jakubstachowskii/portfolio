# CONTENT-CHECKLIST.md — co musi dostarczyć Piotr

Kod można budować równolegle, ale bez tego strona nie wystartuje. Odhaczaj na bieżąco.

## Podstawy (przed Fazą 2)
- [ ] Imię i nazwisko w formie do wyświetlania + monogram/logo (albo zgoda, żeby Claude Code zaprojektował monogram z inicjałów)
- [ ] Rola w jednym zdaniu (PL/EN), np. „Programista aplikacji desktop i web”
- [ ] Zdanie wartości do hero (PL/EN) — co robisz i dla kogo, konkretnie
- [ ] Status: otwarty na oferty? (tak/nie, praca/freelance/oba)
- [ ] E-mail do kontaktu (najlepiej na własnej domenie), LinkedIn, GitHub
- [ ] Domena (sprawdź dostępność: `imienazwisko.dev`, `.pl`, `imie.dev`)
- [ ] Wybór kierunku wizualnego z top 3 stylów z Refero (Faza 1a). Jeśli jakiś styl z https://styles.refero.design/ już Ci się podoba, podaj link, a trafi na shortlistę.

## Projekty (przed Fazą 3) — na każdy projekt
- [ ] Nazwa, rok, typ, status, Twoja rola, czas trwania
- [ ] Problem: kto miał problem i jaki (2–4 zdania)
- [ ] Rozwiązanie: 3–6 kluczowych funkcji
- [ ] Stack (lista technologii)
- [ ] 2–3 wyzwania techniczne + jak je rozwiązałeś (fragmenty kodu mile widziane)
- [ ] Efekt w liczbach — **tylko prawdziwe** (zaoszczędzony czas, liczba użytkowników, mniej błędów)
- [ ] Zrzuty ekranu w wysokiej rozdzielczości (min. 2400 px szerokości, PNG), czyste dane testowe
- [ ] Opcjonalnie: krótkie nagranie ekranu 10–20 s (bez dźwięku), do konwersji na webm/mp4
- [ ] Linki: demo / repo / pobranie — albo informacja, że projekt jest poufny
- [ ] Wybór 3–4 projektów wyróżnionych na stronie głównej

Kandydaci: aplikacja do awizacji · Command Center · Kalkulator mebli · platforma komunikacji wewnętrznej (Firebase) · system rozliczania podwykonawców (GPS) · SDK licencji (jeśli działa).

## O mnie (przed Fazą 4)
- [ ] Zdjęcie: dobre światło, neutralne tło, min. 1600 px, uśmiech/naturalnie
- [ ] 3–4 akapity o sobie (możesz dać szkic — Claude Code wygładzi, ale nie wymyśli faktów)
- [ ] Doświadczenie: staż w firmie Leon — daty, 3–5 osiągnięć
- [ ] Edukacja: technikum (daty), WSB Merito (start, przewidywany koniec)
- [ ] Umiejętności z podziałem: używam codziennie / znam / uczę się
- [ ] Czy chcesz wspomnieć o sporcie / zainteresowaniach (tak/nie)
- [ ] CV jako PDF w PL i EN (`cv-pl.pdf`, `cv-en.pdf`)

## Konta i klucze (przed Fazą 5)
- [ ] Konto Vercel (połączone z GitHubem)
- [ ] Konto Resend + zweryfikowana domena nadawcy → `RESEND_API_KEY`
- [ ] Cloudflare Turnstile → site key + secret key
- [ ] GitHub fine-grained token (read-only, public repos) → `GITHUB_TOKEN`
- [ ] Umami (cloud lub self-host) albo Vercel Web Analytics
