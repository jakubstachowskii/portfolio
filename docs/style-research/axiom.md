# Axiom: „Terminal window at midnight”

- **Refero:** https://styles.refero.design/style/c809190a-035c-458d-87ed-4758807dd84e · źródło: https://axiom.co
- **Tryb:** ciemny
- **Zrzut:** `screens/axiom.jpg`

**Nastrój.** Okno terminala o północy: płaska czerń, wszystko w monospace, jeden pomarańczowy kursor.

**Paleta.** `#000` / `#111` / `#191919` / `#202020`, tekst `#eee` / `#b4b4b4`, akcent ember `#da5c2c`.

**Fonty.** BerkeleyMono (komercyjny) dla **całego** tekstu, Inter tylko w drobnych przypisach.

**Kształty.** 2px dla kart, przycisków i inputów, pigułki tylko dla tagów. Praktycznie bez cieni.

**Komponenty.** Prompt `~/` nad nagłówkiem, pole strzałek `>>>` jako tekstura hero, karty case study z 2px lewym obramowaniem w akcencie, strzałki `→` po etykietach akcji.

**Dla nas.** Bardzo „dev”, ale same mono w długich case studies męczą. Mocna inspiracja dla linii terminala i 404, słaba dla treści.
