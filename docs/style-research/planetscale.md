# PlanetScale: „Terminal man-page in daylight”

- **Refero:** https://styles.refero.design/style/a6771960-b826-49bc-9ee7-7f7a5e29642b · źródło: https://planetscale.com
- **Tryb:** jasny
- **Zrzut:** `screens/planetscale.jpg`

**Nastrój.** README / man-page w świetle dnia. Cały UI w ui-monospace, achromatyczny, z jednym pomarańczowym CTA `#f35815` i niebieskimi linkami `#0b6ec5`.

**Kształty.** 0px dla kart, inputów i tabów, pigułki dla przycisków. 2px pomarańczowa belka przed nagłówkiem sekcji.

**Komponenty.** Siatka logotypów w komórkach, panel z tabami, blok kodu i danych, pasek ogłoszeń.

**Dla nas.** Świetna surowość i szybkość, ale minimalne miejsce na zrzuty projektów, a długie treści w mono są męczące.
