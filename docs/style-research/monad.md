# Monad: „Editorial tech journal on warm parchment”

- **Zrzut:** `screens/monad.jpg`

**Nastrój.** Techniczny magazyn literacki: pergamin `#f6f3f1`, nagłówki Untitled Serif 400, cały UI w ABC Diatype Mono, jeden akcent Lake Blue `#2b59d1`.

**Kształty.** Pigułki 100px dla przycisków i tagów, karty 40px.

**Komponenty.** Diagram pipeline'u z węzłami-pigułkami, pastelowe gradientowe „mgły”, akordeon FAQ.

**Dla nas.** Ciekawe połączenie szeryfu i mono, ale fonty są komercyjne, promienie 40px są „miękkie” i mało inżynierskie, a tryb jest tylko jeden.
