# Linear: „Midnight precision instrument”

- **Refero:** https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1 · źródło: https://linear.app
- **Tryb:** ciemny
- **Zrzut:** `screens/linear.jpg`

**Nastrój.** Precyzyjny instrument: `#08090a`, biały tekst o ciasnym trackingu, wagi 400–510, obramowania 0.5px. Jeden akcent acid lime `#e4f222`.

**Fonty.** Inter Variable (cv01, ss03, zero) + Berkeley Mono (ID zadań, skróty).

**Kształty.** 6px (przyciski, inputy) / 12px (karty) / pigułki. Bez cieni, z wewnętrznymi highlightami.

**Komponenty.** Ramki zrzutów produktu, pasek logotypów, gradientowa „podłoga” hero.

**Dla nas.** Wzorcowa precyzja i dobre ramy na zrzuty. To jednak najczęściej kopiowany styl w SaaS i portfolio devów (ryzyko „szablonu”), a jasnego trybu nie ma.
