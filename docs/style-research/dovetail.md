# Dovetail: „Blueprint grid under a black moon”

- **Refero:** https://styles.refero.design/style/108e2695-6970-47d5-b5b0-eea8fc34e048 · źródło: https://dovetail.com
- **Tryb:** ciemny
- **Zrzut:** `screens/dovetail.jpg`

**Nastrój.** Nocne centrum dowodzenia: prawie czarne tło z delikatną siatką milimetrową, biała typografia i jedna miękka iskra indygo.

**Paleta.** `#000` → `#0a0a0a` (canvas) → `#141414` (karta) → `#1e1e1e` → `#313131` (hairline). Tekst `#fff` / `#a7a7a7`. Jedyny akcent `#6798ff`, wyłącznie funkcyjnie (ikony, wykresy, linki).

**Fonty.** Inter 400–600 z ujemnym trackingiem rosnącym ze skalą (−0.036em przy 64px). JetBrains Mono 12px uppercase +0.07em jako „pieczątki” i eyebrow.

**Kształty i głębia.** 4 / 8px, nav w pigułkach. Głębia **przez luminancję powierzchni, bez cieni**.

**Charakterystyczne komponenty.** Biały przycisk główny + ghost, nawigacja z pigułek, bloki statystyk (KPI), eyebrow w mono, tag BETA, podgląd dashboardu.

**Layout.** 1200px, 80px między sekcjami. Hero: tekst po lewej, produkt po prawej. Rzędy KPI w 3 kolumnach.

**Dla nas.** Dark-first zgodny z PLAN. Siatka tła = nasz element sygnaturowy z §2.4. Para Inter + JetBrains Mono jest identyczna z naszą hipotezą, więc trzeba ją zmienić (zasada min. 1 innego fontu).
