# Vercel: „Typeset terminal on white paper”

- **Refero:** https://styles.refero.design/style/f24daf3a-d43f-4dec-85a9-8ac1d5148a03 · źródło: https://vercel.com
- **Tryb:** jasny (Geist ma oficjalny dark, łatwo dorobić)
- **Zrzut:** `screens/vercel.jpg`

**Nastrój.** Zdyscyplinowany monochrom: `#fafafa`, czarna typografia, hairline, zero koloru dekoracyjnego. Terminal złożony w druku.

**Paleta.** `#fafafa` / `#fff` / `#ebebeb` / skala szarości do `#171717`. Zieleń `#297a3a` tylko przy potwierdzeniach CLI.

**Fonty.** Geist Sans 400–450 z trackingiem −0.06em przy 56–64px, Geist Mono 11–12px uppercase w etykietach.

**Kształty.** 6px. Głębia przez warstwowe box-shadow 1px (ring), nie drop-shadow.

**Komponenty.** Panel wyjścia CLI (`▲` / `✓`), eyebrow w mono, odwrócona karta, siatka kart cech.

**Dla nas.** Bezpieczny i dostępny, ale bardzo rozpoznawalny („podróbka Vercela”). Brak miejsca na osobowość bez mocnych zmian.
